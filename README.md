# MMEA-WI: Weighted Indicator-Based Evolutionary Algorithm for Multimodal Multi-objective Optimization

[![Paper](https://img.shields.io/badge/DOI-10.1109%2FTEVC.2021.3078441-blue)](https://doi.org/10.1109/TEVC.2021.3078441)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
![PlatEMO](https://img.shields.io/badge/PlatEMO-v4.2%20officially%20included-green)

Matlab code for "Weighted indicator-based evolutionary algorithm for multimodal multi-objective optimization"

> W. Li, T. Zhang, R. Wang, and H. Ishibuchi, "Weighted Indicator-Based Evolutionary Algorithm for Multimodal Multiobjective Optimization," *IEEE Transactions on Evolutionary Computation*, vol. 25, no. 6, pp. 1064–1078, 2021.
> DOI: [10.1109/TEVC.2021.3078441](https://doi.org/10.1109/TEVC.2021.3078441)

The paper PDF is included in this repository.

## Usage:
Copy the folder to PlatEMO\Algorithms\Multi-objective optimization.
Please note that, the latest version of PlatEMO(v4.2) contains the source code of MMEAWI.
Run PlatEMO and choose MMEAWI
Enjoy!
